# SHL-Alubin: website concept

An unsolicited concept for SHL-Alubin, Israel's largest aluminium extruder (Kiryat Bialik, since 1958),
by Kikkey. **Not the official SHL-Alubin website.** Every page carries a fixed notice saying so, and every
page and response is `noindex`.

> **Cold metal. Hot process.** One story from a 480 °C billet to a cool, precise, finished profile.
> The interface is cold, Swiss and technical; heat appears only where the process is hot.

## Run it

```bash
npm install
npm run dev          # http://localhost:3000/style-tile/
npm run build        # static export to ./out
npm run check:tokens # fails if tokens.css and tokens.ts drift apart
```

The build is a static export (`output: "export"`, trailing slashes), deployable as plain files to
Cloudflare Pages (`public/_headers`) or Vercel (`vercel.json`); both send `X-Robots-Tag: noindex`.

## Design system

- **Tokens:** `src/styles/tokens.css` is the source of truth (Tailwind v4 `@theme`), mirrored for JS
  (GSAP, WebGL) in `src/design/tokens.ts`; `scripts/check-tokens.mjs` keeps them in sync.
- **Type:** nine fluid steps generated by `scripts/type-scale.mjs`. At 1600 px each step's cap height
  is an ISO 3098 lettering height (2.5 to 40 mm); at 360 px it relaxes to phone sizes.
- **Space:** 4 px grid (`--spacing: 0.25rem`); margins and gutters step per breakpoint so they stay on it.
- **Time:** an 80 ms grid (80 / 160 / 240 / 400 / 640 / 960 / 1120 ms), one house curve
  `cubic-bezier(0.22, 1, 0.36, 1)`, never bouncy.
- **Colour:** Alu White, Alu Mid, Graphite, Ink and one accent, Billet Glow `#FF5A1F`, used only for heat,
  active states and the primary CTA. Derived Alu Deep `#5A626A` exists only for secondary text on light.
- **Surfaces:** `data-surface="sheet" | "press" | "graphite"` sets semantic colours; components only
  use semantic names, so they work on light and dark without variants.
- **RTL:** logical properties everywhere; drawings, numerals and part IDs never mirror.

## Structure

```
src/app/(lab)/            lab routes (own root layout): /style-tile, later /hero-lab
src/styles/               tokens.css, base.css, components.css
src/components/ui/        Button, TextField/RangeField, Chip, ProfileCard, SpecTable, Toast
src/components/drawing/   ProfileDrawing (ISO 128/129 cross-sections), Dim, Callout
src/components/material/  BrushedMetal (WebGL anisotropic shading)
src/lib/geometry/         profile geometry in mm, area, kg/m at 2.70 g/cm³
src/content/              specimen copy in EN / DE / HE
```

Fonts: Geist and Geist Mono (SIL OFL, via the `geist` package), IBM Plex Sans Hebrew (SIL OFL,
Hebrew subset only, `src/fonts`).
